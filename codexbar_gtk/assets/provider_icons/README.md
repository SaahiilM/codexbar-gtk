# Provider artwork

`ProviderIcon-*` and `Brand-ProviderIcon-*` files are copied from the upstream
CodexBar project's `Sources/CodexBar/Resources` directory. The GTK frontend uses
the monochrome icons tinted with each provider's accent color, and uses an
upstream curated brand variant when one is available.
