# Legacy assertion map: mixed app and settings tests

This map covers every test method in `tests/test_app.py` and
`tests/test_python_settings_facade.py` at the BUILD113 assignment base. It
records native Rust tests that exercise the same contract independently of the
Python package. The commit removes 26 methods from `test_app.py` plus one
additional settings-facade parity method; the separate permissive CLI
reconfiguration method remains Python-only. It is an assertion-group map, not
evidence that the entire Python test suite or runtime can be deleted. Rust
GTK/widget interaction is outside this backend target; any such assertions are
called out separately.

## GTK/widget boundary

The removed assertion groups are domain/service and persistence checks, not
GTK widget checks. `test_app.py` does not construct GTK widgets. Reset-credit
text formatting and the dashboard model projection now have Rust coverage;
actual GTK rendering and interaction remain UI acceptance work. This map does
not pass UG or authorize legacy runtime removal by itself.
